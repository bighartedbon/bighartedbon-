# ⚽ 2D Ball-Kicking Arena

A fast-paced, interactive 2D local multiplayer sports/arcade game built with HTML5, CSS3, and vanilla JavaScript. Challenge a friend on the same screen, master variable-power kicks, collect game-changing power-ups, and score to win the match!

---

## ✨ Features

* **Local Two-Player Action:** Control competing players on a single screen with distinct movement controls.
* **Physics & Collision Detection:** Smooth player-to-ball momentum transfer, wall bouncing, and precise hitbox interactions.
* **Variable Kick Power:** Hold down or time your strikes to unleash high-velocity shots.
* **Dynamic Power-Ups:** Randomly spawning items on the pitch offering **Speed Boosts** and **Mega-Kick** capabilities.
* **Goal-Scoring Logic & Audio:** Automatic goal detection, score tracking, match countdown timers, and retro sound effects generated programmatically via the **Web Audio API**.
* **Immersive Pitch Design:** Styled football pitch complete with custom zones, goals, and visual indicators.

---

## 🕹️ Controls

| Action | Player 1 (Red Zone) | Player 2 (Blue Zone) |
| :--- | :--- | :--- |
| **Movement** | `W`, `A`, `S`, `D` | Arrow Keys (`↑`, `↓`, `←`, `→`) |
| **Kick / Strike** | `Spacebar` | `Enter` / `Numpad 0` |

---

## 🛠️ Tech Stack

* **Language:** Vanilla JavaScript (ES6+)
* **Graphics & Rendering:** HTML5 Canvas API
* **Audio:** Web Audio API (Synthesized sound effects without external audio assets)
* **Environment:** Developed and tested in VS Code / Modern Web Browsers
